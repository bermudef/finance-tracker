## Project Overview

I am building a personal finance web application for personal use that helps users organize and understand their finances through dashboards, analytics, and AI-powered insights.

The application should answer questions such as:

- Where is my money going?
- Am I saving enough?
- Can I afford this house?
- How much debt should I pay down?
- What is my current net worth?
- How are my investments performing?

The application should eventually become a professional-quality portfolio project demonstrating full-stack software engineering, cybersecurity, cloud architecture, and data analytics skills.
